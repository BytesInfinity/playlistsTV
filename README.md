# playlistsTV
IPTV Playlists targeted for specific group interests for use with IPTV players.

## Overview

This repository hosts custom M3U playlist files for remote access and maintenance.
Playlists are organized by user group (eg. grp1.m3u). Each group has its own playlist URL.

## Playlist Group Description

| Group | Description |
|---|---|
| grp1.m3u | `Filtered group of News, Documentary, Ambient, Classic TV, Sports channels` |
| grp2.m3u | `Filtered group of TV channels` (potential future) |

## Usage

1. Obtain the appropriate raw playlist URL for your group.
2. In your IPTV player, add the playlist as a remote playlist using the supplied URL.
3. Refresh the playlist in your IPTV player when updates are needed.

## Updates and Maintenance

- Playlist contents may be updated as needed.
- Existing playlist URLs are intended to remain stable.
- IPTV player may need to refresh a playlist before changes become visible.

## Important Notes

- This repository hosts playlist files; it does not host or guarantee the availability of the referenced streams.
- Stream availability depends on the respective source.
